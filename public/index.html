Every JSON setting

FieldAccepted valuesWhat it does

removeBackground accepts only true or false. Choose the treatment separately with cutrisMode and cutrisQuality. Mode, quality, and auto crop apply when removal is on.

Shared settings and multiple JSONs

Use defaults for shared settings and prompts for up to 25 entries. Individual prompt settings override defaults. Options may also be grouped under settings. Omitted choices use the composer.

Arrays, JSONL, and consecutive JSON objects are also accepted. For explicit blocks, place ---PROMPT--- on its own line between complete JSON objects or arrays. Insert separator adds it for you. Blank lines do not split text prompts.

Use double quotes, real booleans, and no trailing commas. To keep a structured JSON image description as one prompt, put that object inside the prompt field.

Examples leave your current draft unchanged.
